# Second collection: 13 new works

Five original model-generated images and eight original code-motion/interactive cases have been added, alongside the original four cases: 17 works in total. The code cases explore orbital motion, an isometric paper city, a woven field, rain at a window, a simplified prism, kinetic lettering, a fictional transit network and a two-color print. Parameter/color variants are not counted as separate works.

Each code case includes source, an interactive page, an offline single-file HTML, provenance and a silent technical preview. These previews are not completed films or audio reviews. 53 Node tests and the original motion-core checks pass; all eight technical previews decode completely. Browser/mobile testing remains unverified.

The five new images include full accepted prompts and production facts. Exact image-model versions were not disclosed. Two rejected transparent attempts are not included as public image assets or counted as successes; their existence and rejection reasons remain recorded. The accepted seed-library image is an opaque-background 2D image with a 3D aesthetic, not a real 3D model.

This repository publication does not change the separate gallery website’s access settings. Public reuse licensing remains undecided. Originality and copyright are not legal guarantees.
